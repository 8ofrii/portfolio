## 🚀 Quick Deployment Guide

This portfolio is built with pure HTML5, CSS3 (Glassmorphism + Cyber Neon theme), and modern JavaScript. It requires zero build steps or server runtime.

### Option 1: Deploy on Render (Recommended)
1. Push this folder (`mahmoud_zanaty_portfolio`) to your **GitHub** account repository (e.g. `mahmoud-zanaty-portfolio`).
2. Log in to [Render Dashboard](https://dashboard.render.com/).
3. Click **New +** -> **Static Site**.
4. Connect your GitHub repository.
5. Set:
   - **Name**: `mahmoud-zanaty-portfolio`
   - **Build Command**: *(Leave empty)*
   - **Publish Directory**: `./` (or `root`)
6. Click **Create Static Site**. Render will deploy it instantly with a free SSL certificate!

---

### Option 2: Deploy on Vercel
1. Install Vercel CLI: `npm i -g vercel` or log in to [Vercel Dashboard](https://vercel.com).
2. Import your GitHub repository.
3. Select **Other** as framework preset and click **Deploy**.

---

### Option 3: Deploy on Netlify
1. Log in to [Netlify](https://app.netlify.com/).
2. Drag and drop this folder (`mahmoud_zanaty_portfolio`) into Netlify's **Deploy Site** area.
3. Your site will be live instantly!

---

### Option 4: Deploy on GitHub Pages
1. Push this code to a GitHub repository.
2. Go to **Settings** -> **Pages**.
3. Under **Branch**, select `main` / `master` and folder `/ (root)`.
4. Click **Save**.

---

## 🛠 Local Preview Instructions

You can preview the website locally anytime:
- **VS Code**: Right click `index.html` and select **Open with Live Server**.
- **Python**: Run `python -m http.server 8000` inside this folder and open `http://localhost:8000`.
- **Node.js**: Run `npx serve .` inside this folder.
